# Inayat Ali Academic Website

This folder is a framework-free academic website for GitHub Pages.

## Add your files

1. Put your portrait at `images/profile.jpg`.
2. Put gallery photographs at `images/gallery/photo1.jpg` through `photo4.jpg`.
3. Put the latest CV at `files/CV.pdf`.
4. Update publication records and profile links directly in `index.html`.

## Publish with GitHub Pages

Upload the contents of this folder to the root of a GitHub repository, then open **Settings → Pages**, choose **Deploy from a branch**, select the `main` branch and `/ (root)`, and save.

No build step or framework is required.
